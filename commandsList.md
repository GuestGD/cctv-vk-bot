**1. Проверка камер и свежих записей**

**Посмотреть последние 5 записанных видео (с размером и точным временем):**

```bash
!cmd ls -lht ~/Videos/videos_$(date +%d.%m.%Y)/* | head -n 6
```

**Проверить, писала ли какая-то камера за последние 15 минут:**

```bash
!cmd find ~/Videos -name "*.mkv" -mmin -15
```

**Посмотреть последние 10 строк лога загрузчика в ВК (узнать, всё ли улетает без ошибок):**

```bash
!cmd journalctl -u vk-watcher.service -n 10 --no-pager
```

**Проверить статус службы самого Agent DVR:**

```bash
!cmd systemctl status AgentDVR --no-pager
```

**2. Проверка сети и связи на даче**

**Проверить пинг до конкретной камеры (узнать, не отвалилась ли она от роутера):**

```bash
!cmd ping -c 3 192.168.1.37
```

**Узнать текущий внешний IP-адрес дачного интернета/модема:**

```bash
!cmd curl -s ifconfig.me
```

**Проверить пинг до внешнего интернета (Яндекс/Google):**

```bash
!cmd ping -c 3 ya.ru
```

**3. Состояние железа и накопителя**

**Посмотреть температуру процессора:**

```bash
!cmd cat /sys/class/thermal/thermal_zone*/temp | awk '{print $1/1000 " °C"}'
```

**Узнать, сколько места занимает каждая суточная папка с видео:**

```bash
!cmd du -sh ~/Videos/videos_*
```

**Посмотреть детальную занятость всех разделов диска:**

```bash
!cmd df -h /home
```

**Узнать топ-5 процессов, которые сильнее всего грузят CPU прямо сейчас:**

```bash
!cmd ps aux --sort=-%cpu | head -n 6 | awk '{print $3"% CPU | "$11}'
```

**4. Экстренное обслуживание (если забился диск)**

**Удалить все суточные папки с видео старше 14 дней (если кончается место на диске):**

```bash
!cmd find ~/Videos -maxdepth 1 -type d -name "videos_*" -mtime +14 -exec rm -rf {} +
```
