# CCTV VK Bot

Бот для управления камерами видеонаблюдения через ВКонтакте.

## Установка
```bash
git clone https://github.com/ВАШ_АККАУНТ/cctv-vk-bot.git
cd cctv-vk-bot
```

## Запуск:
```bash
python3 CamsSetup.py
```
### или
```bash
python3 CamsSetup.py "vk1.a.ТОКЕН" ID_ГРУППЫ ВАШ_ЛИЧНЫЙ_ID_VK
```
